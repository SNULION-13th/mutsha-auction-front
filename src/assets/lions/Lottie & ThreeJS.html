애니메이션, 굳이 필요할까요?

혹시.. ‘그냥 보이기만 하면 되지 굳이 애니메이션까지 필요한가…’라고 생각하고 계신가요?
사실 웹과 모바일 앱 개발에서 애니메이션은 단순한 시각적 장식 이상의 역할을 합니다. 사용자 경험(UX)을 향상시키는 중요한 수단으로, 사용자의 행동을 안내하고, 앱의 피드백을 제공하며, 인터페이스에 생동감을 더해요. 애니메이션은 사용자와 애플리케이션 간의 상호작용을 더 직관적이고 이해하기 쉽게 만들어줍니다! 이러한 애니메이션의 적절한 사용은 사용자가 앱을 사용하는 과정을 더 즐겁고 만족스럽게 만듭니다. 따라서 우리는 애니메이션을 통해 사용자 경험을 어떻게 향상시킬 수 있는지 고민해볼 필요가 있는거죠.
물론 이미 앞에서 다루었듯, CSS + JS 조합으로도 애니메이션은 구현할 수 있어요. 그렇지만 더 다이나믹하고 생동감 넘치고 화려하고 휘황찬란한 애니메이션을 만들고 싶은데 그걸 일일이, 장인 정신을 가지고 CSS 를 통해 만들기란.. 현실적으로 힘들겠죠? 아마 우리에겐 그것 말고도 개발할 게 엄청 많을테니까요 (그것까지 해낼 수 있다면 .. 당신은 정말 멋쟁이입니다..)
그럴 때 Lottie를 활용한다면, 무척 간단하면서도 훨씬 더 멋진 프로덕트를 만들 수 있습니다! ​

import TransitionOverlay from "@/components/TransitionOverlay"; import { TransitionScenario } from "@/components/TransitionOverlay"; import { createContext, PropsWithChildren, useCallback, useContext, useState, } from "react"; import { useNavigate } from "react-router-dom"; type PlayArgs = { scenario: TransitionScenario; to?: string }; type Ctx = { playing: boolean; playTransition: (args: PlayArgs) => void; }; const TransitionCtx = createContext<Ctx | null>(null); export function TransitionProvider({ children }: PropsWithChildren) { const nav = useNavigate(); const [open, setOpen] = useState(false); const [scenario, setScenario] = useState<TransitionScenario>("highest"); const [target, setTarget] = useState<string | undefined>(undefined); const playTransition = useCallback(({ scenario, to }: PlayArgs) => { setScenario(scenario); setTarget(to); setOpen(true); }, []); return ( <TransitionCtx.Provider value={{ playing: open, playTransition }}> {children} <TransitionOverlay open={open} scenario={scenario} onDone={() => { const t = target; setOpen(false); setTarget(undefined); if (t) nav(t); }} /> </TransitionCtx.Provider> ); } export function useTransition() { const ctx = useContext(TransitionCtx); if (!ctx) throw new Error("useTransition must be used within TransitionProvider"); return ctx; }

@react-three/fiber (a.k.a. r3f)
Three.js를 React 환경에서 사용할 수 있게 해주는 라이브러리.
일반적으로 Three.js는 DOM 구조와는 별개로 캔버스 위에 3D 씬을 그리지만
r3f
가 React와 Three.js를 연결해 주며,
r3f
는 React의 컴포넌트와 상태 관리를 활용해 직관적으로 3D 그래픽을 구현할 수 있도록 해줍니다!
@react-three/drei
@react-three/fiber 와 함께 사용되는 유틸리티 라이브러리.
자주 쓰이는 Three.js 구성 요소와 기능들을 미리 만들어서 제공하는 아주 고마운 친구입니다. ​
